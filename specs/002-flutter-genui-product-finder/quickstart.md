# Quickstart

In `examples/flutter-a2ui-playground`:

```sh
flutter pub get --enforce-lockfile
flutter analyze
flutter test
flutter run -d chrome
```

Open `?lng=es` for Spanish. Play the three replay chips, submit the signup form, and reset. Use a key only for an optional live check; reset must remove it.

From the site root, `npm run build` compiles the demo into `public/demos/flutter-a2ui-playground/` and writes `public/downloads/flutter-a2ui-playground.zip`.
